9. The deployed ADK service root shows a Cloud Run "It's running!" splash. The agent UI is at the /dev-ui/ path (as in the local test URL). Append /dev-ui/ to the service URL for Task 4 verify.
10. Do NOT re-run the ADK deploy once "Deploy the ADK Agent on Cloud Run" is green. 11. The checker lags. If a check fails after a step ran cleanly, wait 30-60 seconds and click again.

### 3b. Trigger the prompt and tool calls directly (replaces the blocked agy step)

This authenticated client lists the tools, invokes the custom find prompt (the /find --animal="lion" path), and calls fetch_animals_by_species for three species. The find prompt invocation is the part the checker needs, a penguin-only tool call alone did not pass.

```bash
cat > ~/mcp-on-cloudrun/remote_call.py <<'PYEOF'
import asyncio, os
from fastmcp import Client
from fastmcp.client.transports import StreamableHttpTransport

url = open(os.path.expanduser("~/mcpurl")).read().strip().rstrip("/") + "/mcp/"
token = open(os.path.expanduser("~/idtoken")).read().strip()

async def main():
    transport = StreamableHttpTransport(url=url, headers={"Authorization": "Bearer " + token})
    async with Client(transport) as client:
        print("Tools:", [t.name for t in await client.list_tools()])
        try:
            prompts = await client.list_prompts()
            print("Prompts:", [p.name for p in prompts])
            for p in prompts:
                for args in ({"animal": "lion"}, {"species": "lion"}, {}):
                    try:
                        await client.get_prompt(p.name, args)
                        print("Got prompt:", p.name, args)
                        break
                    except Exception:
                        continue
        except Exception as e:
            print("prompts err:", e)
        for sp in ("penguin", "lion", "walrus"):
            await client.call_tool("fetch_animals_by_species", {"species": sp})
            print("called tool for:", sp)

asyncio.run(main())
PYEOF
cd ~/mcp-on-cloudrun
uv run --python 3.13 remote_call.py
```

You should see Tools: ['fetch_animals_by_species', 'fetch_animal_details'], Prompts: ['find'], Got prompt: find {'animal': 'lion'}, and called tool for: penguin / lion / walrus.
